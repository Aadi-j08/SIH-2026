# Contributing

1. Branch from `main` (`feat/…` or `fix/…`).
2. Keep changes focused; run `pytest -q` and `cd frontend && npm run typecheck`.
3. Open a PR with a short summary and how you tested.
4. Do not commit secrets, `.env`, or `*.db` files.
5. Prefer clear commit messages (what + why). No force-push to `main`.

Design / UI: follow Direction A in `docs/design/` and existing portal tokens in `styles.css`.
